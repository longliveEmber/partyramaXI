Window backgrounds for the party list.

Put PNG files in this folder, press Rescan, then choose one in /pxi config -> Party List -> Appearance -> Background:
set Background to "PNG, cut in nine" and pick the Picture.

 - Border cut (9-slice): for pictures with a decorated border, set it to the width of that border in the picture (in pixels).
   The corners stay sharp while the middle stretches. 0 stretches the whole picture.
 - Placed: "Whole list" uses one picture for the window; "Every card" uses it for each member's card.
 - Transparent PNGs work. Power-of-two sizes (256, 512, 1024 px) load most reliably.

The pictures here were made for PartyramaXI and are free to use and change.
