Icon packs: one folder per pack, e.g. packs\HXUI-HD\0.png .. 639.png (named by status id). See ..\README.txt.
No packs come with PartyramaXI: put the ones you like here and press Rescan (or /pxi fx packs).
A pack can build on another: put base.txt in it with the other pack's folder name on the first line, and keep only the
pictures that differ. Missing pictures then come from that other pack.
